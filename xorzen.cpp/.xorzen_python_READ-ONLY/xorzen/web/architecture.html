The HASS Paradigm

Moving beyond static transformers to dynamic, hybrid pathways.

SSM (State Space Models)

We use S4D (Structured Diagonal) kernels with an O(L log L) parallel scan. This provides the model with linear scaling for infinite-length context windows, outperforming standard self-attention on long sequences.

Local Attention

High-resolution local context is maintained through sliding-window multi-head attention, ensuring the model preserves fine-grained semantic relationships.

Adaptive Router

The "brain" of the HASS block. It uses uncertainty and complexity metrics to decide whether a token needs full attention, a fast SSM pass, or can skip the layer entirely.

ZMoE: Disk-Based Intelligence

Traditional MoE requires massive VRAM to keep experts in memory. XorZen-Zero solves this by sharding experts to disk and using a high-speed LRU (Least Recently Used) cache. This allows a 277M model with 192 experts to run on a standard CPU with 16GB RAM, as only the active experts are swapped into memory.
