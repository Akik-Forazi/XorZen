Deploying Superintelligence

From installation to your first training run.

1. Setup Environment

Ensure you have Python 3.13+ and PyTorch installed.

pip install -r requirements.txt
python speed/setup_speed.py build_ext --inplace

2. Prepare Your Data

Convert your raw text into XorZen's high-speed binary format.

from xorzen.data import txt_to_bin
from xorzen.tokenizer import load_pretrained

tokenizer = load_pretrained('xorzen_65k')
txt_to_bin('my_data.txt', 'train.bin', tokenizer)

3. Initialize the Flagship

Load the 277M flagship model and apply the Speed Booster.

import xorzen
from xorzen.speed.booster import SpeedBooster, SpeedProfile

model = xorzen.zero_277M()
booster = SpeedBooster(model.config, profile=SpeedProfile.LIGHTNING)
booster.apply(model)

4. Start Training

from xorzen.training import train
trainer = train(model, 'train.bin', epochs=10)
trainer.train()
